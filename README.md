# 🍔 Qravito - Food Ordering Application

Qravito is a full-stack food ordering platform that allows users to browse menus, add items to cart, and place orders with a seamless and responsive experience.

---

## 🚀 Features

- 🔐 User Authentication & Authorization
- 🍕 Browse food items by category
- 🛒 Add to cart and manage orders
- 📦 Place and track orders
- 🔍 Search and filter food items
- 📱 Fully responsive UI

---

## 🛠️ Tech Stack

**Frontend**
- React.js
- Tailwind CSS (if used)

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

**Other Tools**
- JWT Authentication
- REST APIs
